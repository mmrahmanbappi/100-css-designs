Questions people ask

Are these CSS templates really free?

Yes. Every design is released under the MIT license. You can use them for personal sites, client work and paid products without asking.

Do I need a framework to use them?

No. Each template is one HTML file with the CSS inside it. There is no build step, no npm and no framework. Open it in a browser and it works.

How often are new designs added?

New designs are added in batches until all 100 are live. Star the GitHub repo to see new ones as they arrive.

Can I use these templates for client projects?

Yes. The MIT license allows commercial use. A link back is welcome but not required.
