![Vaporwave CSS template preview](preview.png)

Free vaporwave website template for a synth music label. Pink and purple sky, a retro desktop window, a marble bust and a checker floor. Live demo.

## What is vaporwave?

Vaporwave is a 2010s internet art style that remixes the 80s and 90s: pastel pink and purple skies, old computer windows, marble statues, palm trees and shopping mall music.

The desktop window copies classic 90s system buttons with light and dark borders. The checker floor is a repeating conic gradient tilted back, and the bust is a few rounded shapes with glowing shades.

## What you get

- Pink to purple sunset sky
- Retro desktop window with a working playlist
- Checker floor made with repeating-conic-gradient
- Marble bust with glowing shades in CSS
- Monoton and VT323 retro fonts

## The key CSS

```css
.floor {
  background: repeating-conic-gradient(#fff 0 25%, #1a0933 0 50%) 0 0 / 80px 80px;
  transform: perspective(500px) rotateX(60deg);
}
.win {
  background: #c0c0c0;
  border: 2px solid; border-color: #fff #404040 #404040 #fff;
}
.tb { background: linear-gradient(90deg, #000080, #1084d0); color: #fff; }
```

## How to use

1. Download `demo.html` from this folder.

3. Upload it anywhere. One file, no build step.
