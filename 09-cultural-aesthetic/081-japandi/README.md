Free Japandi website template for a ceramics shop. Warm neutrals, oak tones, soft shapes and a calm layout mixing Japanese and Nordic style. Live demo.

## What is japandi?

Japandi mixes Japanese calm with Scandinavian comfort. The colors are rice paper, linen, oak and charcoal, the shapes are soft, and there is a lot of empty space so each object can breathe.

The hero is a still life drawn in CSS: pots on an oak shelf and a single branch. The type pairs Shippori Mincho, a Japanese serif, with a quiet sans, and nothing on the page competes for attention.

## What you get

- Warm neutral palette with oak and moss accents
- CSS still life of pots and a branch on a shelf
- Shippori Mincho headings for a gentle Japanese feel
- Underline style text link instead of a loud button
- Three category columns with plenty of space

## The key CSS

```css
:root {
  --rice: #f2ede4; --linen: #e6ddd0; --oak: #b89572;
  --char: #2f2b27; --moss: #737a5b;
}
h1 { font-family: "Shippori Mincho", serif; font-weight: 500; line-height: 1.3; }
.pot { border-radius: var(--r); box-shadow: inset -10px -6px 18px rgba(0, 0, 0, .12); }
.btn { border-bottom: 1px solid var(--char); padding-bottom: 4px; }
```

## How to use

1. Download `demo.html` from this folder.
2. Change the text, colors and links.
3. Upload it anywhere. One file, no build step.
